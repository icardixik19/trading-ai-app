Sık Sorulan Sorular

Merak ettiklerin.

Confidence Score nasıl hesaplanıyor?+
6 faktörün ağırlıklı ortalaması: Trend (%25), Momentum (%20), Hacim (%15), S/R (%15), Volatilite (%10), MTF (%15). 70+ güçlü sinyal, 50 altı zayıf sinyal anlamına gelir.
BIST verileri gerçek zamanlı mı?+
BIST hisse verileri BigPara/Yahoo Finance üzerinden 15 dakika gecikmeli. Kripto CoinGecko API ile gerçek zamanlı (~60 saniye). Altın Yahoo Finance ile anlık.
AI asistanı kullanmak için ne gerekiyor?+
Ücretsiz Groq API key yeterli. console.groq.com adresine kayıt olup key oluşturun, Ayarlar sekmesine girin.
Platform gerçek işlem açıyor mu?+
Hayır. TRDAI yalnızca teknik analiz ve sinyal üretimi yapar. Auto-Execution modu bu versiyonda devre dışıdır. Binance API entegrasyonu yakında.
Verilerim güvende mi?+
TRDAI hiçbir kişisel veri toplamaz. API keyler yalnızca tarayıcının localStorage'ında saklanır, sunucuya gönderilmez.
Mobil cihazda çalışıyor mu?+
Evet. Platform mobil öncelikli tasarlanmıştır. Alt navigasyon ile tüm özellikler parmak dostu erişilebilir.
